КАК ЗАГРУЗИТЬ
1. Распакуйте ZIP.
2. Скопируйте ВСЕ файлы из архива в существующий репозиторий sezonchik-site,
   сохранив папки scripts/, .github/workflows/ и server/. Не загружайте сам ZIP как файл в корень репозитория.
3. Сделайте commit/push в ветку main.
4. Откройте GitHub → Actions → «Apply SEZONCHIK V14 page fixes».
   При первом добавлении workflow должен запуститься от коммита; если не запустился,
   откройте workflow и нажмите Run workflow.
5. Убедитесь, что задача завершилась зелёным статусом и создала коммит
   «Apply SEZONCHIK V14 static SEO, booking and delivery improvements».
   Если push завершился ошибкой доступа, проверьте:
   Settings → Actions → General → Workflow permissions → Read and write permissions.
   Без запуска этой задачи статические HTML-файлы останутся прежними.
6. Проверьте /privacy.html, /consent.html, /trees.html, карточку Селена,
   /dostavka.html?city=komsomolsk и главную в приватном окне.

КОГДА ПРЯМЫЕ ЗАКАЗЫ ЗАРАБОТАЮТ
- Публикация ZIP не запускает сервер.
- В ZIP есть патч серверного Python-кода. Чтобы включить реальный приём,
  нужно развернуть server/orders.py на сервере в России, настроить
  MAX_BOT_TOKEN / MAX_USER_ID, HTTPS и DNS orders.sezonchik27.ru, затем ORDERS_ENABLED=1.
- До тех пор сайт честно сохраняет оформление через мессенджеры.
- Никогда не загружайте токен MAX или пароли в публичный GitHub.
- Убедитесь, что соблюдены требования по локализации, договору с хостером
  и организации обработки персональных данных. Политику рекомендуется проверить
  с юристом с учётом реальных процессов и хостинга.
