Главная полностью переделана под искусственные ёлки: новые цвета, композиция,

для которой были предоставлены дополнительные ракурсы.

Велосипеды, электротранспорт, бассейны и батуты сохранены отдельными разделами.
Закупочные цены на сайте не публикуются. Наличие подтверждает магазин.

КАК ОБНОВИТЬ САЙТ
1. Распаковать архив.
2. Скопировать содержимое папки sezonchik-site-main в папку существующего
   репозитория сайта с заменой файлов. Папку .git не трогать.
3. В GitHub Desktop проверить изменения, нажать Commit, затем Push origin.
4. После завершения GitHub Pages открыть сайт с обновлением кеша (Ctrl+F5).

Архив подготовлен, публикация не выполнялась.
Проверено: цены 70 вариантов, фильтры, сообщения для заказа, ссылки на локальные
ресурсы, синтаксис JavaScript. Автоматическая визуальная проверка в браузере
в среде подготовки была недоступна. После публикации просмотрите главную
и каталог на телефоне и компьютере.
