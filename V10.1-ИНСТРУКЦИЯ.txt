СЕЗОНЩИК 10.1 — PREMIUM CHRISTMAS FINAL

УСТАНОВКА
1. Исходная версия сайта — СЕЗОНЩИК 10.0.
2. Откройте папку проекта GitHub (там, где index.html).
3. Распакуйте содержимое этого ZIP в КОРЕНЬ проекта, сохранив папки assets/ и elki/.
4. Разрешите замену существующих файлов. НЕ удаляйте остальные файлы сайта.
5. GitHub Desktop: Changes → Commit to main → Push origin.
6. Дождитесь успешной публикации в Vercel и откройте сайт в инкогнито.
7. Проверьте навигацию, подбор, бронь, кнопки WhatsApp/Telegram/MAX и тестовые ссылки ?ref=01,02,03,04.

СОСТАВ: только файлы, изменённые относительно V10.0. Файлы каталога и страницы SKU не содержат правок цен/описаний.
Шрифты Cormorant Garamond, Manrope, Marck Script подгружаются по сети из Google Fonts. Если сеть блокирует Google Fonts, появится запасной шрифт.
В блоке «Более 6000 семей» сохранён согласованный текст; документальное подтверждение утверждения остаётся ответственностью магазина.
Код 04 сохраняется на 30 дней и передаётся с доступными формами/ссылками, как и в V10.0.

ОСНОВНЫЕ ПРАВКИ
- Главное приветствие: крупное золотое ЁЛКИ + курсив в Хабаровске.
- Герой раздела — праздничная гостиная с ёлкой справа.
- Пять преимуществ с узнаваемыми иконками, без утверждения о 15 годах на рынке.
- Три большие карточки фактур хвои с круглой детализацией.
- Фирменные значки мессенджеров Telegram, WhatsApp, MAX.
- Контактная панель отдельно под категориями; ссылки сохраняются.
- Единые кнопки и мобильная адаптация.
- Разрешена загрузка веб-шрифтов в _headers, если платформа применяет этот конфиг.
- Исправлена проверка уже добавленного реферального кода 04.

ПРОВЕРКИ
Статически: цены и описания всех страниц каталога совпадают с 10.0.
Браузер: автономные превью разделов на 375, 390, 430, 1440 px, переполнения по ширине нет.
Ограничение: полная навигация по локальному сайту в среде браузерного теста блокируется; тест кликов на опубликованном Vercel проводится после установки.
