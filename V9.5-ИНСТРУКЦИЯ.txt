СЕЗОНЩИК / V9.5 / ГОТОВЫЙ МИНИ-ПАТЧ (ПОВЕРХ V9.4)

УСТАНОВКА
1. Сначала должен быть установлен V9.4 (партнёрские коды 01, 02, 03).
2. Откройте папку вашего репозитория сайта (там, где index.html).
3. Распакуйте ZIP прямо в корень папки сайта. Согласитесь на замену index.html.
4. Убедитесь, что появилась папка assets/v95/ и файл v95-visual.css.
5. В GitHub Desktop нажмите Commit, затем Push origin.
6. После обновления GitHub Pages обновите страницу Ctrl+F5 / очистите кэш.

ИЗМЕНЕНИЯ
- Шесть одобренных карточек высот: 150/180/210/240/270/300 см (полные изображения и тексты).
- Карточки по-прежнему открывают каталог с фильтром по высоте.
- Блок подарков: семья перед магазином в полный рост, без обрезки.
- Блок доставки: праздничная иллюстрация карты всей России, в том числе на телефоне; надпись «Акцент на Дальнем Востоке» удалена.
- На карте можно нажать для увеличения.
- Промокоды партнёров 01/02/03 из V9.4 сохранены без изменений.
- Прайс, артикулы и модели ёлок не изменены.

ВАЖНО
- Карта — декоративная визуализация, не навигационная схема; подписи и линии условные.
- Патч не публикуется автоматически: нужен Push в GitHub.
