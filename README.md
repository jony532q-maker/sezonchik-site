# СЕЗОНЩИК — подготовка 17 новых размеров ёлок
Дата: 27.10.2026

Источник: GitHub `jony532q-maker/sezonchik-site`, ветка `main`, каталог `trees.html`.
Розничные цены: проект из таблицы «СЕЗОНЩИК — 17 новых размеров и цены».

## Что делает патч
- Дополняет имеющиеся размеры у 10 существующих моделей, без дублирования карточек.
- Сохраняет ВСЕ текущие размеры, цены, названия, ссылки на фото, фильтры и формы.
- Обновляет основной каталог `trees.html` и затронутые страницы `elki/*.html`.
- Синхронизирует размерные таблицы, SEO-описания и Product/Offer JSON-LD.
- При добавлении 400 см добавляет высоту 400 см в общий фильтр каталога.
- Результат собирает в отдельный ZIP. Исходный сайт не изменяется.

## Безопасный запуск (16 размеров)
1. В репозитории GitHub нажмите `Code → Download ZIP`. Извлеките архив.
2. Установите Python 3.9+ (не нужны никакие дополнительные библиотеки).
3. Из папки с этим скриптом запустите:

   Windows:
   `py apply_tree_sizes.py "ПУТЬ_К_РАСПАКОВАННОМУ_САЙТУ" --output SEZONCHIK_PATCH.zip`

   macOS/Linux:
   `python3 apply_tree_sizes.py "/path/to/sezonchik-site" --output SEZONCHIK_PATCH.zip`

   Указывайте папку, где лежит `trees.html`, а не папку уровнем выше.

4. Скрипт создаст ZIP только с изменёнными файлами. **Не загружайте этот ZIP на сайт до согласования проектных цен.**
5. После утверждения цен распакуйте содержимое ZIP в корень репозитория с сохранением папки `elki`, затем проверьте сайт на ПК и телефоне.

## Дополнительный, неподтверждённый вариант
Чтобы включить также артикул 2108, высота 400 см, проектная цена 79 990 ₽,
добавьте `--include-400` в команду. Получится 17 размеров вместо 16.
Закупочная цена 50 000 ₽ и доступность 400 см требуют проверки.

## Контроль
- Открываются карточки и страницы всех 10 моделей.
- Работает фильтр по новой высоте и по бюджету.
- Цена меняется при выборе размера, выбранный размер попадает в заявку.
- SEO-таблица на странице каждой модели соответствует общему каталогу.
- Изображения и существующие акции сохранены.
- Проверены ПК и телефон перед публикацией.
